## 📚 Descrição

Esta room aborda um dos conceitos mais fundamentais em Linux/Unix: **shells**. Você aprenderá sobre os diferentes tipos de shells disponíveis, como eles funcionam e quando usá-los.

## 🏫 Objetivos de Aprendizado

- [ ] Entender o que é um shell e seu papel no sistema operacional
- [ ] Conhecer os diferentes tipos de shells disponíveis (bash, sh, zsh, fish, etc)
- [ ] Aprender sobre shell variables e environment variables
- [ ] Compreender shell scripting básico
- [ ] Trabalhar com diferentes shells e suas características
- [ ] Executar comandos e scripts em diferentes ambientes shell
